# Shoe Shop

A responsive shoe shopping web application built with JavaScript and Tailwind CSS. The project includes a frontend application and a separate server component for handling project data.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- JSON Server
- Git
- GitHub

## Features

- Responsive shoe shopping interface
- Product-focused user interface
- Dynamic product data
- Separate frontend and server structure
- Responsive styling with Tailwind CSS
- Organized frontend project structure

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

Clone the repository:

git clone https://github.com/rasoulmahjoobi/Shoe-Shop.git

Navigate to the project directory:

cd Shoe-Shop

Install the dependencies:

cd server
npm install

Start the server according to the project configuration.

Then open the frontend files from the Web directory in your development environment.
